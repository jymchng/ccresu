Configuration

One YAML file, validated at startup, with environment variables that always win.

Download .md

ccresu reads ~/.config/ccresu/config.yaml by default, or the path given with --config. The full annotated example lives in configs/config.example.yaml; every field in it is validated, and an invalid value is a startup error rather than a silent fallback.

Resolution order, first match wins: --config PATH (or -c PATH), then the CCRESU_CONFIG environment variable, then the default path. A leading ~ is expanded in all three, and everything derived from the file — such as the API token beside it — follows the file actually in use.

Environment overrides

Every field can be overridden with a CCRESU_ prefixed variable: upper-case the section and field, and join nesting with a double underscore. The environment always takes precedence over the file, which keeps secrets out of it.

Detection patterns

Custom patterns are Go regular expressions matched against normalised text: lower-cased, single-spaced, with curly quotes and dashes folded to ASCII. A rule can require a reset time and carries its own confidence, which is compared with detector.threshold.

Secrets

Prefer CCRESU_TELEGRAM__BOT_TOKEN over writing the token into the file, and keep the file readable only by you: chmod 600 ~/.config/ccresu/config.yaml. The API never returns the token, and logs redact it.
