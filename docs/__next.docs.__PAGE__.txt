20:T6df,# Documentation

> Everything ccresu does, in the order you need it.

- [Installation](https://jymchng.github.io/ccresu/docs/installation/) — Install a released binary with a single line, or build from source with Go 1.26 or newer.
- [Tutorial: your first recovered session](https://jymchng.github.io/ccresu/docs/tutorial/) — Thirteen steps from an empty machine to a session that was resumed for you, then the same state driven by hand and over the API.
- [Configuration](https://jymchng.github.io/ccresu/docs/configuration/) — One YAML file, validated at startup, with environment variables that always win.
- [CLI reference](https://jymchng.github.io/ccresu/docs/cli/) — Fourteen commands, five global flags, and exit codes a script can branch on.
- [How recovery works](https://jymchng.github.io/ccresu/docs/recovery/) — From the limit banner to a verified resume, through an explicit persisted state machine.
- [Telegram notifications](https://jymchng.github.io/ccresu/docs/telegram/) — Optional, deduplicated, off the recovery path: a Telegram outage can never block a resume.
- [Deployment](https://jymchng.github.io/ccresu/docs/deployment/) — Run ccresu as a user-level systemd service, or under any supervisor that can restart a process.
- [Security](https://jymchng.github.io/ccresu/docs/security/) — Loopback-only API, a token for every write, no terminal automation and no telemetry.
- [Troubleshooting](https://jymchng.github.io/ccresu/docs/troubleshooting/) — Diagnose with doctor, inspect and history, then match the symptom.
- [Known limitations](https://jymchng.github.io/ccresu/docs/limitations/) — What ccresu deliberately does not do, and where it can still be defeated.

Source: https://jymchng.github.io/ccresu/docs/
