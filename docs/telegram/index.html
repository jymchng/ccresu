Telegram notifications

Optional, deduplicated, off the recovery path: a Telegram outage can never block a resume.

Download .md

Create a bot and find the chat

  1. Talk to @BotFather, run /newbot, and copy the token it returns.
  2. Send the bot a message so the chat exists.
  3. Read your chat id from curl https://api.telegram.org/bot<token>/getUpdates (the chat.id field), or use a public id such as @channelname for a channel.

Configure

ccresu doctor reports telegram disabled or telegram configured, and the API exposes the same state at GET /api/v1/telegram/status with the token redacted.

Events

EventSent when
limit detectedA usage-limit banner was matched and recorded.
waitingThe session is waiting for its reset time (off by default: it is the noisiest event).
recovery startedA resume attempt is about to run.
recovery successThe resume was verified: same session id, longer transcript.
recovery failureAn attempt failed and another one is scheduled.
permanent failureThe attempt budget is spent or the error is not retryable.
session completedThe session finished normally, so no recovery is needed.

Delivery behaviour

  • Messages are HTML-escaped: a project path or session id containing < or & cannot break the message or inject markup.
  • The templates are HTML, so parse_mode: HTML is the only accepted value; MarkdownV2 and Markdown are rejected at config validation rather than arriving as literal markup.
  • HTTP 429 responses honour retry_after, and transient failures retry with backoff.
  • Delivery state is persisted per event, so the same event is not sent twice across restarts.
  • Sending happens off the recovery path: a slow or failing Telegram API cannot delay or fail a resume.
  • The bot token is redacted from every log line and error message, including request errors that embed the URL.

Bot tokens are credentials

Anyone with the token can post as your bot. Keep it in the environment or a 0600 file, and revoke it with @BotFather if it leaks. ccresu never logs it and never returns it from the API.
